# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## tl;dr

- Be respectful in issues, PRs, and discussions
- Assume good faith; criticize the work, not the person
- Don't post Forager-related promotion in unrelated communities (see CLAUDE.md
  Rule 9 for the rationale)
- Anonymize receipts before contributing them

## Reporting

If you experience or witness behavior that violates this code of conduct,
please open a private issue or contact the maintainers directly via the email
in the repository's GitHub profile.

Reports will be handled confidentially. Severity-appropriate responses range
from a private clarification to a permanent ban from project participation.
